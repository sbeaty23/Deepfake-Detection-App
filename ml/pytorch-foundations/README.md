# PyTorch Foundations — Fashion-MNIST CNN

## Purpose
This sandbox exercise was created to learn the fundamentals of PyTorch image classification before developing our senior capstone's deepfake photo detection model.

## Implementation
- Built a custom CNN with two convolutional layers.
- Used Fashion-MNIST (60,000 training images and 10,000 test images).
- Trained for three epochs with CrossEntropyLoss and the Adam optimizer.
- Evaluated the model on held-out test images.
- Saved trained weights to a `.pth` checkpoint.
- Created a separate prediction script that loads saved weights without retraining.

## Results
- Test accuracy: **90.03%**
- Example prediction: **Ankle boot**
- Actual label: **Ankle boot**

## Running the Project
Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Train and evaluate the CNN:

```bash
python train.py
```

Run inference using the saved checkpoint:

```bash
python predict.py
```

The prediction script requires a checkpoint generated by the training script.
